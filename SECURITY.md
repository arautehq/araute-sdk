# Security Policy

## Supported versions

Only the latest stable release of `@araute/sdk` receives security fixes.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** button on the repository's Security page. Do not create a public issue or pull request for a security report.

Include the affected SDK version, runtime, impact, reproduction steps, and any relevant sanitized logs or proof of concept. Never include API keys, payment data, or other secrets.

Maintainers will use the private report to coordinate investigation, remediation, and disclosure with the reporter.
